# Університетський портал

**Призначення:** Інформаційно-комунікаційний портал для автоматизації доступу студентів до розкладу, онлайн-замовлення довідок та отримання оголошень від деканату.

**Тип системи:** Web (веб-додаток).

**Автор:** Ойцюсь Олександр

## Технології
- Backend: Node.js / Express
- Frontend: React / Vue
- База даних: PostgreSQL
